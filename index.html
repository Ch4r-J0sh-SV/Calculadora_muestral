¿Cómo se calculó? (Desglose matemático paso a paso)

▾

Se aplica la fórmula de tamaño muestral para estimación de proporciones en población finita:

n = [ N · Z² · p · (1 - p) ] / [ e² · (N - 1) + Z² · p · (1 - p) ]

¿Cómo funciona esta calculadora? (Fundamentos estadísticos)

▾

1. Tamaño de la población (N) y corrección por finitud

Cuando la población es finita y conocida, la selección de un individuo reduce el conjunto restante, reduciendo ligeramente la varianza del estimador. El término (N - 1) en el denominador incorpora el factor de corrección para poblaciones finitas (FPCF), evitando muestreos innecesariamente grandes.

2. Nivel de confianza y coeficiente Z

Representa el porcentaje de intervalos de confianza calculados a partir de muchas muestras independientes que contendrían el verdadero parámetro poblacional. Los valores críticos de la distribución normal estándar más habituales son:

  • 90% de confianza: Z = 1.645 (α = 0.10)
  • 95% de confianza: Z = 1.960 (α = 0.05, estándar científico más adoptado)
  • 99% de confianza: Z = 2.576 (α = 0.01, alta precisión)

3. Margen de error (e)

Es la tolerancia máxima de error que se está dispuesto a aceptar entre la proporción observada en la muestra y la proporción real de la población total. Un margen del ±5% (0.05) significa que si la muestra arroja 60%, se estima que el valor real poblacional se encuentra entre 55% y 65%.

4. Proporción esperada (p = 50% como caso más conservador)

El producto p · (1 - p) representa la varianza de una distribución de Bernoulli. Este producto alcanza su valor máximo en 0.50 · 0.50 = 0.25. Cuando no se cuenta con información de estudios previos, se asume p = 50% para garantizar el tamaño de muestra más seguro y suficiente posible.

5. Redondeo estricto hacia arriba (Techo: ⌈n⌉)

Dado que los elementos de una muestra son discretos (personas, encuestas, piezas inspeccionadas), cualquier fracción decimal exige redondear hacia el siguiente entero superior. Redondear hacia abajo dejaría el tamaño muestral por debajo del límite requerido para garantizar el nivel de confianza y margen de error especificados.
